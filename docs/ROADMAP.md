# Roadmap

## v0.2 — Calibrate

- Overlay a user-entered observed sun interval against the geometric prediction.
- Store named scenarios locally.
- Export and import compact scenario-only JSON.
- Add compass-measurement guidance and magnetic-declination notes.

## v0.3 — Obstructions

- Window reveal depth.
- Horizontal overhang/balcony.
- Simple exterior rectangular obstruction.
- Interior curtain/blind percentage as an explicitly non-geometric layer.

## v0.4 — Rooms

- Multiple windows.
- Editable 2D floor plan.
- Target regions and plant-canopy volumes.
- Seasonal animation with an accessible static alternative.

## Integrations under consideration

- Home Assistant sensor comparison.
- Embeddable Web Component.
- GeoJSON-free URL fragment sharing with an explicit coordinate warning.

Weather, cloud accounts, and opaque AI recommendations are not roadmap requirements.
