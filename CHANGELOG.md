# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-07-28

### Added

- Local-first React planner with English and Simplified Chinese interfaces.
- Compact Meeus-derived solar-position engine.
- IANA time-zone and daylight-saving handling.
- Rectangular-window ray intersection and direct-sun interval calculation.
- Room heatmap and full-year monthly profile.
- CSV and versioned JSON exports.
- Headless CLI plus importable TypeScript package.
- Example scenarios, documentation, automated tests, CI, Pages, and release workflows.
